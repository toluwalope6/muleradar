# Demo data licence and attribution

`sample.parquet` and `ground_truth.json` are derived from the **IBM Transactions for Anti Money Laundering (AML)**
dataset (HI-Small files) by IBM, published on Kaggle by `ealtman2019`:
https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

The source data is **simulated** (generated by IBM's AML simulator); it contains no real customers or transactions.

Licence: **Community Data License Agreement – Sharing – Version 1.0** (CDLA-Sharing-1.0),
https://cdla.io/sharing-1-0/. This derived data is shared under the same licence.

Changes made by MuleRadar (`backend/data.py`): a ~45k-row sample keeping every row labelled laundering plus a
random sample of normal rows; amounts converted to USD using rates inferred from the dataset's own
cross-currency transfers; accounts renamed `<bank>_<account>`; `HI-Small_Patterns.txt` parsed into
`ground_truth.json`.
